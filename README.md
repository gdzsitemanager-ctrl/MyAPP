# WebApk Builder

Android-приложение: выбираете HTML или ZIP, название и логотип — получаете готовый APK прямо на телефоне, без интернета.

## Как получить APK самого билдера
1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки (включая `.github`).
2. Откройте вкладку **Actions → Build APK → Run workflow** (или просто сделайте commit в main).
3. Через ~5 минут скачайте артефакт **WebApkBuilder** (внутри `app-debug.apk`) и установите.

## Как это работает
- Модуль `template` — крошечная WebView-оболочка. Она собирается в CI и кладётся в assets билдера.
- Билдер на телефоне подменяет в шаблоне: `assets/www` (ваш сайт), PNG-иконку, название и пакет, затем подписывает APK (v1+v2).
- Пакет приложения выводится из названия, поэтому пересборка с тем же названием обновляет установленное приложение.
- Сайт открывается по адресу `https://app.local/`, так что работают fetch, ES-модули, localStorage.

## Журнал
Вкладка «Журнал» хранит этапы сборки и подробные ошибки (в том числе аварийные закрытия). Можно скопировать или отправить.

## Ограничения
- Название — до 64 байт (кириллица ~32 символа).
- Приватный ключ подписи не включён в репозиторий по соображениям безопасности. Для публикации в Google Play используйте собственный ключ подписи.
- Одиночный HTML не подтянет внешние css/js/картинки — для таких сайтов берите ZIP.
