# WebApk Builder

Android-приложение: выбираете HTML или ZIP, название и логотип — получаете готовый APK прямо на телефоне, без интернета.

## Игровой прототип DRONE WARFARE: FRONTLINE
В каталоге `game/` находится запускаемый браузерный 3D-прототип в формате 16:9: выбор стороны (оператор БПЛА / условная ПВО), процедурный полигон, боты, управление полётом, HUD/радар, смена погоды и тестовый визуальный эффект.

Чтобы запустить локально, скачайте `game/index.html` и откройте в браузере с подключением к интернету (Three.js загружается с CDN). Если браузер блокирует ресурсы при открытии файла, из корня репозитория выполните `python -m http.server 8000` и откройте `http://localhost:8000/game/`.

Это первый играбельный прототип, а не финальная AAA-игра на Unreal Engine: модели и окружение пока процедурные, боевые параметры условные. Веб-прототип отдельный от APK-билдера.

## Как получить APK самого билдера
1. Откройте репозиторий на GitHub и дождитесь завершения GitHub Actions.
2. Откройте вкладку **Actions → Build APK** и выберите последний запуск.
3. Скачайте артефакт **WebApkBuilder** (внутри `app-debug.apk`) и установите.

## Как это работает
- Модуль `template` — WebView-оболочка. Она собирается в CI и кладётся в assets билдера.
- Билдер на телефоне подменяет в шаблоне сайт (`assets/www`), PNG-иконку, название и пакет, затем подписывает APK (v1+v2).
- Пакет приложения выводится из названия, поэтому пересборка с тем же названием обновляет установленное приложение.
- Сайт открывается по адресу `https://app.local/`, так что работают fetch, ES-модули, localStorage.

## Журнал
Вкладка «Журнал» хранит этапы сборки и подробные ошибки (в том числе аварийные закрытия). Можно скопировать или отправить.

## Подпись APK и безопасность
- Приватные ключи подписи и сертификаты не включены в репозиторий.
- Чтобы функция создания APK работала, добавьте собственные файлы `app/src/main/assets/signing/key.pk8` и `app/src/main/assets/signing/cert.der` локально на устройстве/в сборочную среду. **Не коммитьте приватный ключ** в GitHub.
- Для публикации в Google Play используйте свой постоянный ключ подписи и храните его отдельно от репозитория.

## Ограничения
- Название — до 64 байт (кириллица ~32 символа).
- Одиночный HTML не подтянет внешние css/js/картинки — для таких сайтов берите ZIP.


## FRONTLINE Messenger — интерфейс мессенджера
В каталоге `messenger/` находится адаптивный тёмный интерфейс мессенджера в фирменной чёрно-белой палитре с лаймовым акцентом и собственной SVG-эмблемой-галочкой. Открыть: [messenger/index.html](messenger/index.html).

**Важно:** текущая версия — интерактивный UI-прототип. Вход и чаты демонстрационные, а сообщения сохраняются только локально в браузере. Для настоящих аккаунтов, входа по почте/телефону, SMS-кодов, доставки сообщений между устройствами и защиты данных необходимо подключить сервер авторизации, базу данных и SMS/email-провайдера. Пароли и секреты не должны встраиваться в HTML или храниться в открытом виде.
